## 1. Cấu trúc thư mục và danh sách tệp tin

- 1250080095_Cao Vũ Ngọc Lan.docx
  Tài liệu báo cáo chi tiết nội dung bài làm (định dạng Microsoft Word).

- 1250080095_UseCase.drawio
  Sơ đồ ca sử dụng (Use Case Diagram) thiết kế bằng diagrams.net (Draw.io).

- 1250080095_Activity_Sequence.drawio
  Sơ đồ hoạt động (Activity Diagram) và sơ đồ tuần tự (Sequence Diagram) thiết kế bằng diagrams.net (Draw.io).

- png/
  Thư mục chứa các hình ảnh xuất từ sơ đồ hoặc tài liệu báo cáo.

- QuanLyThuVien.sql
  Kịch bản tạo cơ sở dữ liệu và bảng dữ liệu cho Microsoft SQL Server.

- Quanlythuvien.zip
  Mã nguồn ứng dụng/dự án Quản lý thư viện.

- lab2.zip
  Thư mục nén chứa bài thực hành Lab 2.

---

## 2. Hướng dẫn cài đặt và chạy thử

1. Cơ sở dữ liệu:
   - Mở SQL Server Management Studio (SSMS).
   - Mở tệp QuanLyThuVien.sql và thực thi (Execute) để khởi tạo database cùng dữ liệu mẫu.

2. Mã nguồn:
   - Giải nén tệp Quanlythuvien.zip.
   - Cập nhật lại chuỗi kết nối cơ sở dữ liệu (Connection String) nếu cần.
   - Mở và chạy dự án bằng IDE tương ứng (Visual Studio, VS Code,...).

3. Xem sơ đồ thiết kế:
   - Mở trực tiếp các tệp có đuôi .drawio tại trang https://app.diagrams.net/ hoặc xem các hình ảnh kết xuất có sẵn trong thư mục png/.
