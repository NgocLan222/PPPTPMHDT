CÀI ĐẶT CƠ SỞ DỮ LIỆU
- Mở file "SQLQuery1.sql" bằng SQL Server Management Studio (SSMS).
- Nhấn Execute (F5) để khởi tạo database "eShoppingDB" và nạp dữ liệu mẫu.

 CẤU HÌNH & CHẠY ỨNG DỤNG
- Giải nén file "eshopping.zip".
- Mở solution (.sln) bằng Visual Studio và bấm phím F5 để chạy chương trình.
- Cấu hình chuỗi kết nối tại "Data/Db.cs":
  Server=.;Database=eShoppingDB;Trusted_Connection=True;
  (Chỉnh sửa lại Server Name cho khớp với máy chấm nếu cần).
