
1. CÀI ĐẶT CƠ SỞ DỮ LIỆU
- Mở file "QLyCongTyDuLich.sql" bằng SQL Server Management Studio (SSMS).
- Nhấn phím F5 (Execute) để tự động tạo cơ sở dữ liệu "QuanLyCongTyDuLich" cùng toàn bộ 16 bảng và dữ liệu mẫu khởi tạo.
2. CẤU HÌNH & CHẠY ỨNG DỤNG
- Giải nén file "QuanLyCongTyDuLich.zip".
- Mở file giải pháp (.sln) bằng Visual Studio 2022.
- Kiểm tra chuỗi kết nối trong file "App.config" cho khớp với tên SQL Server của máy chấm (mặc định cấu hình Data Source=. hoặc Data Source=(localdb)\MSSQLLocalDB).
- Nhấn Rebuild Solution (Ctrl + Shift + B) và bấm F5 để chạy ứng dụng.
3. DANH SÁCH FILE NỘP KÈM
- 1250080095_Cao Vũ Ngọc Lan.docx : Báo cáo đặc tả phân tích, thiết kế UML và kịch bản test case.
- 1250080095.drawio               : File thiết kế các sơ đồ UML 
- QLyCongTyDuLich.sql             : Kịch bản khởi tạo CSDL và nạp dữ liệu kiểm thử.
- QuanLyCongTyDuLich.zip          : Mã nguồn hoàn chỉnh dự án C# Windows Forms (.NET Framework 4.7.2).
- README.txt                      : Hướng dẫn cài đặt và chạy hệ thống.
